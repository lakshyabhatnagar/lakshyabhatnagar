## About Me

I am a third-year undergraduate engineering student at **Netaji Subhas University of Technology, Delhi**, working at the intersection of artificial intelligence, machine learning and backend engineering.

- AI/ML Intern at **Pumpumpum**
- Pursuing B.Tech in **Instrumentation and Control Engineering** at NSUT
- Chairperson of the **IEEE Power & Energy Society Chapter, NSUT**
- Former ML-IoT Intern at the **India Meteorological Department**
- Building AI-assisted developer tools across RAG, security analysis, compliance mapping and backend infrastructure
- Interested in taking AI systems beyond notebooks into reliable, deployable applications

My work primarily involves LLM applications, retrieval systems, machine learning pipelines, backend APIs, security tooling and full-stack AI products.

## Current Focus

- Agentic workflows and LangGraph orchestration
- AI-assisted security and compliance systems

- Production machine learning deployment
- AI system evaluation and observability
